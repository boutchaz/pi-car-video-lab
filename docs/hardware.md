## Before making changes

1. Record the starting configuration without serial numbers, VIN, account details, or network credentials.
2. Inspect and preserve the existing microSD contents; do not flash over an unknown card.
3. Check the proposed power and USB connection against the board and host documentation. Do not assume a computer or vehicle port can power the full setup reliably.
4. Write the first bench experiment and its stop conditions before connecting hardware.
